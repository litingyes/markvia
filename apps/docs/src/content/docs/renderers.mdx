所有 renderer 都消费同一种 `RenderDocument`。因此同一段 Markdown 的语义可以跨输出目标保持一致。

  </TabItem>

  </TabItem>
</Tabs>

## HTML

HTML renderer 适合静态页面、服务端输出和不需要客户端 runtime 的场景：

```ts
import { createMarkdown } from '@markvia/core'
import { htmlRenderer } from '@markvia/html'

const html = createMarkdown().render(source, htmlRenderer)
```

输出会转义文本，并过滤不安全的 URL 和事件属性。

## React

React 包提供 `Markdown` 组件和 `renderReact` 函数：

```tsx
import { Markdown, renderReact } from '@markvia/react'

;<Markdown content={content} />
```

通过 `components` 可以按 Markdown 节点类型替换目标组件：

```tsx
<Markdown
  content={content}
  components={{
    heading: Heading,
    link: ExternalLink,
  }}
/>
```

## Vue

Vue 包提供同名的 `Markdown` 组件：

```vue
<Markdown :content="content" />
```

组件也支持传入 `document` 或 `stream`，因此静态文档和实时输入可以共享 API。
