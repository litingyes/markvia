# Universal Markdown Runtime

Markvia parses Markdown into a shared Semantic AST and Render IR, then adapts the result to HTML, React, and Vue.

The examples below use the same Markdown source with three renderers:

## Design goals

- A framework-agnostic Markdown runtime contract
- One AST/IR pipeline for static pages, interactive components, and streaming input
- Safe HTML output with stable node IDs
- Extensible document transforms, IR transforms, and code-highlighting hooks

Read the [Getting Started guide](./getting-started/) to install Markvia, or jump to the [renderer guide](./renderers/) and [streaming guide](./streaming/).
