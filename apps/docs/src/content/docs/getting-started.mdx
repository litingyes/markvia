Markvia requires Node.js `>=24`. The package manager examples below use pnpm.

<Steps>

1. Install the runtime and a renderer:

   ```bash
   pnpm add @markvia/core @markvia/html
   ```

2. Create a runtime and choose a renderer:

   ```ts
   import { createMarkdown } from '@markvia/core'
   import { htmlRenderer } from '@markvia/html'

   const runtime = createMarkdown()
   const html = runtime.render('# Hello', htmlRenderer)
   ```

3. Run the project’s type checks and tests:

   ```bash
   pnpm check
   pnpm test
   ```

</Steps>
