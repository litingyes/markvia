`createStream()` 接收 Markdown chunks，并通过订阅回调发出文档和变更信息。已完成块的 ID 会保持稳定，未完成的 fenced code block 也可以在 stream 结束前安全展示。

## Core API

```ts
const stream = runtime.createStream()

stream.subscribe(({ document, changes }) => {
  console.log(document, changes)
})

stream.write('# Hello')
stream.write('\n\nworld')
stream.finish()
```

