HTML renderer 会：

- 转义文本内容。
- 默认将 Markdown 中的 raw HTML 作为转义后的文本处理。
- 只有开启兼容模式时才保留 raw HTML，同时转义 GFM 禁止的标签起始符。
- 只允许安全的生成式 HTML 标签和属性名称。
- 忽略事件属性，例如 `onclick`。
- 拒绝 `javascript:`、`data:` 等不安全 URL。
- 保留不安全链接的文本，并标记 `data-markvia-unsafe-url="true"`。

兼容模式只对 HTML renderer 开放：

```ts
import { createHTMLRenderer } from '@markvia/html'

const renderer = createHTMLRenderer({ allowRawHtml: true })
const html = runtime.render(source, renderer)
```

React 和 Vue 不提供 raw HTML 放行选项，始终把 raw HTML 作为安全文本输出。即使开启 HTML 兼容模式，也不会放行 GFM 禁止的 `iframe`、`script`、`style`、`textarea`、`title` 和 `xmp` 标签起始符。

## 自定义 renderer

如果应用需要不同的安全策略，应在将 Markvia 输出传入 DOM 或模板系统之前进行处理，并继续保持 URL 验证边界。不要把未经验证的用户输入直接作为 Astro 的 `set:html` 内容。
