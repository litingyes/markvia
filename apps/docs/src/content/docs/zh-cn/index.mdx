<CardGrid>
  <Card title="统一语义 pipeline" icon="document">
    只解析一次，保持稳定的节点 ID，并让不同 renderer 共用同一份 Render IR。
  </Card>
  <Card title="默认安全" icon="padlock">
    文本会被转义，不安全 URL 会被拒绝，raw HTML 默认保持不可执行状态。
  </Card>
  <Card title="为变化而生" icon="rocket">
    支持增量 Markdown stream、document transform 和代码高亮 hook，同时保持 renderer contract 不变。
  </Card>
</CardGrid>
