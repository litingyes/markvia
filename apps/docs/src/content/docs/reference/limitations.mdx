Markvia 的 Markdown 兼容性基线是 CommonMark 0.29 + 正式 GFM 0.29。`createMarkdown()` 默认启用 GFM，因此同时覆盖 CommonMark 语法；没有单独的严格 CommonMark 模式。

已覆盖的格式包括：

- CommonMark 的区块、容器、行内语法、引用链接/图片、HTML block、raw HTML、硬换行和 fenced code
- GFM 表格、表格对齐、任务列表、删除线和扩展自动链接
- LF、CRLF、CR、tab、Unicode、无尾部换行、非法 marker、危险 URL 和流式分块边界
- HTML、React SSR、Vue SSR 的统一 IR 输出，以及稳定节点 ID 和块级增量 stream

有意不包含的扩展或能力：

- 脚注、Alerts、MDX、frontmatter、issue/PR 引用和 emoji 等 GitHub 产品层扩展
- Shiki
- Math
- Mermaid
- Component Markdown
- CLI

如果需要扩展语法，优先通过 parser、document transform 或插件边界增加能力，同时保持 HTML、React 和 Vue renderer 共享同一个 IR contract。
