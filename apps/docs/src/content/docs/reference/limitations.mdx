---
title: 当前限制
description: Markvia 0.1 的支持范围和暂未承诺的能力。
sidebar:
  order: 3
---

当前版本优先建立框架无关的 runtime contract，还没有承诺完整 Markdown 兼容性。

已支持的基础语法包括：

- 标题、段落、强调、加粗、删除线和行内代码
- 链接和图片
- 有序列表、无序列表和引用
- fenced code block
- 稳定节点 ID 和块级增量 stream

暂未承诺或暂未包含：

- 完整 CommonMark / GFM 兼容性
- Shiki
- Math
- Mermaid
- Component Markdown
- CLI

如果需要扩展语法，优先通过 parser、document transform 或插件边界增加能力，同时保持 HTML、React 和 Vue renderer 共享同一个 IR contract。
