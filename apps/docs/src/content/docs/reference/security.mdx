HTML renderer 会：

- 转义文本内容
- 只允许安全的 HTML tag 和 attribute 名称
- 忽略事件属性，例如 `onclick`
- 拒绝 `javascript:`、`data:` 等不安全 URL
- 对不安全链接保留文本，并标记 `data-markvia-unsafe-url="true"`

## 自定义 renderer

如果应用需要不同的安全策略，应在进入 DOM 或模板系统之前处理 Markvia 输出，并继续保持 URL 验证边界。不要把未验证的用户输入直接作为 Astro 的 `set:html` 内容。
